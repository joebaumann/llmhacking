# Instructions to preprocess manifestoProjectIssues

- Create account on Manifesto Project site: [https://manifesto-project.wzb.eu/](https://manifesto-project.wzb.eu/)
- Download "Manifesto Project Main Dataset (Party Preferences)" from [https://manifesto-project.wzb.eu/down/data/2024a/datasets/MPDataset_MPDS2024a.csv](https://manifesto-project.wzb.eu/down/data/2024a/datasets/MPDataset_MPDS2024a.csv)
- Place in [data/manifestos/data_raw](data/manifestos/data_raw)
- Then run script.R (need manifesto api key)
